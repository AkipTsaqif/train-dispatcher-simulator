## Key decisions & recent changes

- **2026-09-04:** Fixed platform-dwell easing off-by-one bug in `dispatching-table.tsx`: `atPlatformDwell` previously set `easeX = renderLeg.waypointX` where `renderLeg` was `plan.legs[st.leg]`. But once a train physically arrives at a platform waypoint, `advanceTrain` immediately increments `st.leg` to the _next_ outgoing leg, so `renderLeg.waypointX` was the _subsequent_ station's x (e.g. 136 for JNG-W instead of 424 for JNG). This inflated `leadFactor` to 1.0, pulling the dwelling marker back by the full 26-unit front compensation (to x=398, grid-snapped to 392 at W-Z) while the card read "Berhenti di Jatinegara" (dwelling). Also fixed the approach branch (`dwellsAt(st.leg + 1)`) and departure branch (`st.leg > 0 && plan.legs[st.leg].departAt`) to check the matching leg indices. Result: dwelling trains sit steadily at platform centre `x=424`, and the forward monotonicity test passes with 0 glitches. Added regression test `jatinegara westbound train 5509B dwells at platform centre x=424 without pullback`.
- **2026-09-03:** Fixed Matraman/POK snippet handover step-backward glitch and red NW1 head stopping position in JNG table (`dispatching-table.tsx`):
